## Scope

This is a public portfolio export of an on-premise AI platform. The code and
guides describe the implementation and deployment shape; they do not include
customer data, customer credentials or a verified fresh private-cloud install.
The local run in the root README is intentionally marked partial. Compliance
guides describe implementation controls and setup steps; they are not legal
certification or an audit result.

Legacy session summaries and phase reports were removed from the public tree.
Useful operator, identity, provider, RAG and deployment material is filed
under the folders above.
