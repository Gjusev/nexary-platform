## 1. Introducción

### ¿Qué es Azure OpenAI Service?

Azure OpenAI Service es la oferta de Microsoft que proporciona acceso a los modelos avanzados de OpenAI (GPT-4, GPT-4o, o1, o3-mini, etc.) alojados en la infraestructura cloud de Azure. Combina lo mejor de ambos mundos:

- **Modelos de punta de OpenAI** - GPT-4.1, GPT-4o, o1, o3-mini, DALL-E 3, etc.
- **Infraestructura enterprise de Azure** - Seguridad, cumplimiento, escalabilidad
- **Cumplimiento normativo** - GDPR, ISO 27001, SOC 2, HIPAA, EU AI Act
- **Integración ecosistema Azure** - AI Search, Cosmos DB, Fabric, etc.

### Ventajas Principales para Nexary

| Aspecto | Beneficio |
|---------|-----------|
| **GDPR Compliant** | Datos procesados y almacenados en UE |
| **Certificaciones** | ISO 27001, ISO 27018, SOC 1/2/3, C5 (Alemania) |
| **Data Residency** | Garantía de residencia de datos en UE |
| **No entrenamiento** | Tus datos NUNCA se usan para entrenar modelos |
| **Private Link** | Conexión privada desde tu VNet |
| **RAG Integrado** | Azure AI Search para "on your data" |
| **Enterprise SLA** | 99.9% de disponibilidad garantizada |

## 2. Cumplimiento Normativo

### 2.1 GDPR (General Data Protection Regulation)

Azure OpenAI está **100% compliant** con GDPR:

#### ✅ Compromisos de Datos

```
Tus prompts (inputs) y completions (outputs):
✅ NO están disponibles para otros clientes
✅ NO están disponibles para OpenAI
✅ NO se usan para mejorar modelos sin permiso
✅ NO se usan para entrenar modelos foundation
✅ Permanecen dentro de la geografía UE (con Data Zone)
```

#### ✅ Derechos GDPR Soportados

- **Derecho de Acceso** - Puedes exportar todos tus datos
- **Derecho de Supresión** - Eliminación completa de datos almacenados
- **Derecho de Portabilidad** - Exportar datos en formato estructurado
- **Derecho de Oposición** - Oponerte al procesamiento automatizado
- **Derecho de Rectificación** - Corregir datos inexactos

#### ✅ Bases Legales

- **Interés Legítimo** - Para operaciones de negocio normales
- **Consentimiento** - Para procesamiento especial
- **Contrato** - Para cumplimiento de acuerdos comerciales
- **Obligación Legal** - Para requerimientos regulatorios

## 5. Regiones y Residencia de Datos

### 5.1 Tipos de Despliegue

Azure OpenAI ofrece **3 tipos de despliegue** con diferentes garantías de residencia de datos:

#### 🌍 Global Deployment

```
Procesamiento: Cualquier región global (UE, US, Asia)
Almacenamiento: Región del recurso Azure
Precio: Base (más económico)
SLA: 99.9%
```

**Uso recomendado:** Desarrollo, testing, aplicaciones sin requisitos estrictos de residencia.

#### 🇪🇺 EU Data Zone Deployment (CRÍTICO PARA GDPR)

```
Procesamiento: Cualquier país de la UE
Almacenamiento: Región del recurso Azure (en UE)
Precio: +10% sobre Global
SLA: 99.9%
Garantía: Datos NUNCA salen de la UE
```

**Uso recomendado:** ✅ **Nexary producción** - Cumplimiento GDPR garantizado.

#### 🏛️ Regional Deployment (MÁXIMO CUMPLIMIENTO)

```
Procesamiento: Solo en la región específica
Almacenamiento: Región del recurso Azure
Precio: +20% sobre Global
SLA: 99.9%
Garantía: Máxima residencia de datos
```

**Uso recomendado:** Aplicaciones con requisitos regulatorios estrictos (gobierno, salud, finanzas).

### 7.2 Cliente Type-Safe para Azure OpenAI

```typescript
// lib/ai/azure-openai-client.ts

import { AzureOpenAIClient, OpenAIKeyCredential } from "@azure/openai";
import { ChatCompletion, StreamEvent } from "openai";

export interface AzureOpenAIConfig {
  endpoint: string;
  apiKey: string;
  apiVersion: string;
  deployment: string;
}

export class AzureOpenAIClientWrapper {
  private client: AzureOpenAIClient;

  constructor(config: AzureOpenAIConfig) {
    this.client = new AzureOpenAIClient({
      endpoint: config.endpoint,
      apiKey: new OpenAIKeyCredential(config.apiKey),
      apiVersion: config.apiVersion || "2024-08-01-preview"
    });
  }

  /**
   * Genera una respuesta de chat streaming
   */
  async chatStream(
    messages: Array<{ role: string; content: string }>,
    onChunk: (chunk: string) => void,
    options?: {
      temperature?: number;
      maxTokens?: number;
      topP?: number;
    }
  ): Promise<string> {
    const { deployment } = this.config;

    const stream = await this.client.chat.completions.create({
      deployment,
      messages,
      temperature: options?.temperature ?? 0.7,
      max_tokens: options?.maxTokens ?? 4096,
      top_p: options?.topP ?? 1.0,
      stream: true
    });

    let fullResponse = "";

    for await (const event of stream) {
      if (event.choices && event.choices[0]?.delta?.content) {
        const content = event.choices[0].delta.content;
        fullResponse += content;
        onChunk(content);
      }
    }

    return fullResponse;
  }

  /**
   * Genera embeddings para RAG
   */
  async generateEmbeddings(texts: string[]): Promise<number[][]> {
    const response = await this.client.embeddings.create({
      model: "text-embedding-3-small",
      input: texts,
      dimensions: 1536
    });

    return response.data.map(d => d.embedding);
  }

  /**
   * Chat con función de llamada (tool calling)
   */
  async chatWithTools(
    messages: Array<{ role: string; content: string }>,
    tools: Array<{
      type: "function";
      function: {
        name: string;
        description: string;
        parameters: Record<string, unknown>;
      };
    }>
  ): Promise<{ message: string; toolCalls?: any[] }> {
    const { deployment } = this.config;

    const response = await this.client.chat.completions.create({
      deployment,
      messages,
      tools,
      tool_choice: "auto"
    });

    const choice = response.choices[0];
    return {
      message: choice.message?.content || "",
      toolCalls: choice.message?.tool_calls
    };
  }
}
```

```typescript
import { AzureOpenAIClientWrapper } from "./azure-openai-client";

export class AzureOpenAIProvider implements AIProviderInterface {
  private client: AzureOpenAIClientWrapper;
  readonly providerId = "azure-openai";
  readonly providerName = "Azure OpenAI";

  constructor(config: {
    endpoint: string;
    apiKey: string;
    deployment: string;
  }) {
    this.client = new AzureOpenAIClientWrapper({
      endpoint: config.endpoint,
      apiKey: config.apiKey,
      apiVersion: "2024-08-01-preview",
      deployment: config.deployment
    });
  }

  async streamChatCompletion(
    messages: Array<{ role: string; content: string }>,
    onChunk: (chunk: string) => void
  ): Promise<{ content: string; model: string }> {
    const content = await this.client.chatStream(messages, onChunk, {
      temperature: 0.7,
      maxTokens: 4096
```

### 7.5 Implementación de RAG con Azure AI Search

```typescript
// lib/rag/azure-search-rag.ts

import SearchClient from "@azure/search-documents";
import { AzureKeyCredential } from "@azure/core-auth";

export class AzureSearchRAG {
  private searchClient: SearchClient;

  constructor(config: {
    endpoint: string;
    apiKey: string;
    indexName: string;
  }) {
    this.searchClient = new SearchClient(
      config.endpoint,
      config.indexName,
      new AzureKeyCredential(config.apiKey)
    );
  }

  /**
   * Busca documentos relevantes usando búsqueda vectorial
   */
  async searchDocuments(
    queryEmbedding: number[],
    topK: number = 5
  ): Promise<Array<{ content: string; score: number }>> {
    const searchResults = await this.searchClient.search(queryEmbedding, {
      top: topK,
      vectorSearchOptions: {
        queries: [
          {
            kind: "vector",
            vector: queryEmbedding,
            k: topK,
            fields: ["contentVector"]
          }
        ]
      }
    });

    return searchResults.results.map(r => ({
      content: r.document.content,
      score: r.score || 0
    }));
  }

  /**
   * Indexa un nuevo documento con embeddings
   */
  async indexDocument(
    id: string,
    content: string,
    embedding: number[]
  ): Promise<void> {
    await this.searchClient.uploadDocuments([
      {
        id,
        content,
        contentVector: embedding,
        "@search.action": "upload"
      }
    ]);
  }
}
```

### 7.6 Uso en Next.js (Chat API)

```typescript
// app/api/chat/route.ts

import { AzureOpenAIProvider } from "@/lib/ai/providers/azure-openai-provider";
import { AzureSearchRAG } from "@/lib/rag/azure-search-rag";

// Inicializar providers (singleton)
const azureOpenAI = new AzureOpenAIProvider({
  endpoint: process.env.AZURE_OPENAI_ENDPOINT!,
  apiKey: process.env.AZURE_OPENAI_API_KEY!,
  deployment: process.env.AZURE_OPENAI_DEPLOYMENT!
});

const azureSearch = new AzureSearchRAG({
  endpoint: process.env.AZURE_SEARCH_ENDPOINT!,
  apiKey: process.env.AZURE_SEARCH_API_KEY!,
  indexName: process.env.AZURE_SEARCH_INDEX!
});

export async function POST(req: Request) {
  const { messages, ragPackageIds } = await req.json();

  // Si se solicita RAG, buscar documentos relevantes
  let contextMessages = [...messages];

  if (ragPackageIds && ragPackageIds.length > 0) {
    const lastMessage = messages[messages.length - 1];
    const embedding = await azureOpenAI.generateEmbeddings([lastMessage.content]);
    const docs = await azureSearch.searchDocuments(embedding[0], 5);

    contextMessages = [
      {
        role: "system",
        content: `Contexto relevante:\n${docs.map(d => d.content).join("\n\n")}`
      },
      ...messages
    ];
  }

  // Streaming response
  const encoder = new TextEncoder();
  const stream = new ReadableStream({
    async start(controller) {
      try {
        await azureOpenAI.streamChatCompletion(
          contextMessages,
          (chunk) => {
            controller.enqueue(encoder.encode(`data: ${JSON.stringify({ content: chunk })}\n\n`));
          }
        );
        controller.enqueue(encoder.encode("data: [DONE]\n\n"));
        controller.close();
      } catch (error) {
        controller.error(error);
      }
    }
  });

  return new Response(stream, {
    headers: {
      "Content-Type": "text/event-stream",
      "Cache-Control": "no-cache",
      "Connection": "keep-alive"
    }
  });
}
```
